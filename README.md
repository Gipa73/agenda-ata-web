# 📅 Agenda ATA

L'agenda del personale ATA della scuola: timbrature, saldo ore e banca ore, ferie e permessi secondo il CCNL, turni, appuntamenti, attestati di sicurezza, punteggio di servizio e tanto altro. **Gratuita, senza pubblicità, senza abbonamenti.**

**Novità:** scegli il PDF dei turni della scuola (anche scansionato) e l'app carica da sola i tuoi turni del mese.

## ⬇️ Scarica

**[Scarica Agenda ATA (Android)](https://github.com/Gipa73/Agenda-ATA-download/releases/latest/download/Agenda-ATA.apk)**

### Come si installa
1. Tocca il link qui sopra dal telefono e scarica il file `Agenda-ATA.apk`.
2. Aprilo. Se Android lo chiede, consenti l'installazione da questa fonte (**"Installa app sconosciute"** per il browser o per l'app File): è normale, l'app non è sul Play Store.
3. Se compare l'avviso di Play Protect, scegli **"Installa comunque"**.
4. Apri l'app e segui la guida del primo avvio.

### Come si aggiorna
Quando esce una nuova versione, l'app te lo dice all'apertura con un pulsante per scaricarla. Installa il nuovo file **sopra quello che hai**: i tuoi dati restano al loro posto. Prima di aggiornare è sempre buona regola fare un backup (Profilo → Importa e backup).

## 🔒 Privacy
- Timbrature, profilo, contratti e note restano **solo sul tuo telefono**.
- L'app contatta GitHub solo per controllare se esiste una versione più recente (nessun dato personale).
- Statistiche anonime d'uso (un codice casuale, la versione dell'app e la data di utilizzo): per usare l'app è necessario accettarle. Non contengono nessun dato personale.

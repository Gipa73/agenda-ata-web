# 📅 Agenda ATA

L'agenda del personale ATA della scuola: timbrature, saldo ore e banca ore, ferie e permessi secondo il CCNL, turni, appuntamenti, attestati di sicurezza, punteggio di servizio e tanto altro. **Gratuita, senza pubblicità, senza abbonamenti.**

## 📱 iPhone (e qualsiasi telefono): versione web
**[Apri Agenda ATA nel browser](https://gipa73.github.io/Agenda-ATA-download/web/)**

Come si installa sull'iPhone:
1. Apri il link con **Safari**.
2. Tocca **Condividi** ⬆️ e poi **"Aggiungi alla schermata Home"**.
3. Apri l'app dall'icona sulla Home. Fallo **prima di inserire dati**: i dati dell'icona e quelli di Safari sono separati.

Funziona anche senza rete. Quando esce una nuova versione compare un avviso con il pulsante **Aggiorna**: i tuoi dati restano al loro posto.
Limiti della versione web: niente notifiche ad app chiusa, niente widget, niente blocco con Face ID (gli avvisi compaiono in Home quando apri l'app). I dati sono nel browser del telefono: fai ogni tanto un **backup** (Profilo → Importa e backup).

## 🤖 Android
**[Scarica Agenda ATA (Android)](https://github.com/Gipa73/Agenda-ATA-download/releases/latest/download/Agenda-ATA.apk)**

1. Tocca il link dal telefono e scarica il file `Agenda-ATA.apk`.
2. Aprilo. Se Android lo chiede, consenti l'installazione da questa fonte (**"Installa app sconosciute"**): è normale, l'app non è sul Play Store.
3. Se compare l'avviso di Play Protect, scegli **"Installa comunque"**.

Quando esce una nuova versione, l'app te lo dice all'apertura con un pulsante per scaricarla: installa il nuovo file **sopra quello che hai**.

## 🔒 Privacy
- Timbrature, profilo, contratti e note restano **solo sul tuo dispositivo**.
- Statistiche anonime d'uso (un codice casuale, la versione dell'app e la data di utilizzo): per usare l'app è necessario accettarle. Non contengono nessun dato personale.
- L'app Android contatta GitHub solo per controllare se esiste una versione più recente.
